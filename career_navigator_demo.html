📋 사내 시스템 연계 실데이터 요구 가이드 (HR Data Mapping Guide)
실제 사내 DB와 연동하기 위해 최우선으로 확보해야 할 API 및 테이블 스키마 설계도입니다.

1. 직무 및 역량 표준화 마스터 데이터 (Standardized Job & Skill Taxonomy)

* **필요 항목**: 사내 모든 직종별 고유 식별 코드가 부여된 직무 설명서(Job Specification) 및 **스킬 딕셔너리(Skill Dictionary)**.
* **핵심 데이터**: 각 스킬 레벨(L1 ~ L5)별로 구체적인 임무 완결력과 업무 범위를 판별하는 **행동 지표(Behavioral Anchors) 정량 기준표**.
* **대체 조치**: 마스터 데이터 부재 시, AI 모델에 직무 기술서(JD)와 임직원 자기소개서 요약을 토큰 주입하여 역량을 실시간 레이블링 처리하는 방식 검토 가능.

2. 사내 직무 이동 이력 정량 데이터 (Historical Internal Movement Records)

* **필요 항목**: 과거 5개년 이상 임직원들의 발령 데이터베이스(인사 이동 마스터: 이동 날짜, 이전 부서/직무, 이동 부서/직무, 직급, 성과 등).
* **핵심 데이터**: 직종 간 이동이 주로 발생하는 **허브 노드** 판별을 위한 통계 이동 확률 매개 테이블.
* **대체 조치**: 통계 이력이 누적되지 않았거나 신설 조직인 경우, 리더 그룹 대상 1회성 서베이를 실시하거나 "희망 이동 경로(Intent Data)" 수집 데이터로 모형 보완.

3. 교육 콘텐츠 매핑 테이블 (LMS Course & Skill Mapping Matrix)

* **필요 항목**: 사내 이러닝 플랫폼(LMS), 외부 강좌(Coursera, Udemy), 추천 도서관 등 교육 마스터 코드.
* **핵심 데이터**: 특정 강의를 완료 시 **어떤 스킬(ID)의 숙련도가 향상되는지 규정된 스킬-코스 연결 테이블(Mapping Matrix)**.
* **대체 조치**: 수동 연결이 불가능한 대형 카탈로그의 경우, LLM 임베딩 엔진을 구동해 교육 요약문과 스킬 설명서의 코사인 유사도(Cosine Similarity)를 분석하여 자동 추천 매핑 구성.
